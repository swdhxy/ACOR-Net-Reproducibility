# ACOR-Net anonymous reproducibility package

This package accompanies **ACOR-Net: Occupancy-Guided Multi-Person Activity Count Estimation from WiFi Channel State Information**. It provides frozen record-level outputs, the exact final data partitions, selected configurations, model code, and analyses for auditing the reported count estimates.

The primary setting uses nine activity categories, at most three people, and unseen **complete activity-count combinations**. It is not a cross-person or cross-room holdout. The three splits overlap; initialization runs and overlapping recordings are not independent sensing experiments.

## Two reproduction routes

1. **Audit reported results:** Python standard library only, no CSI, GPU, or model checkpoints required.
2. **Rerun models:** download WiMANS separately, install the tested numerical environment, then use the relocated final configurations. Raw CSI and trained checkpoints are not included. A fresh training campaign has not been rerun for this packaging task; repeated fits may vary across hardware/runtime versions.

## 1. Recompute frozen prediction results

Unzip the archive, change into this directory, and run:

```bash
python scripts/reproduce_tables.py
```

The command checks the original main results from 54 frozen prediction files, independently reproduces 1,872 additional metric values, recomputes the matched-head intervals, and checks 528 follow-up statistics. Newly computed original tables and intervals are written under `_reproduced/`; archived inputs remain under `analysis/`, `experiments/server_results/`, and `followup/results/`.

The original main-analysis check compares 360 scalar values against the archived reports. The additional evaluation archive contains 144 condition evaluations, 36 clean model evaluations, and nine newly trained direct-head runs. Do not interpret these counts as independent datasets.

To regenerate the full coefficient sweep, calibration diagnostics, error partitions and combination-bootstrap analyses, install the numerical environment below and run:

```bash
python followup/analyze_followup.py --output _reproduced/followup
```

The fixed coefficient grid is 0, 0.05, 0.1, 0.25, 0.5, 1, and 2. The original coefficient remains 0.25; the post hoc sweep did not select a replacement model.

## 2. Numerical environment

The training archive records Python 3.11.17, PyTorch 2.6.0+cu124, torchvision 0.21.0+cu124, NumPy 2.2.6, CUDA 12.4, and NVIDIA L20. Use Python 3.11 for the following installation. Select the official CPU or CUDA wheel source appropriate to your machine.

```bash
python -m venv .venv
# Activate the virtual environment using your operating system's command.
python -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
python -m pip install -r experiments/original_release/requirements-tested.txt
python -m pip install -e "experiments/original_release[external]"
```

For CPU-only checks, replace the wheel index above with `https://download.pytorch.org/whl/cpu`. Training uses the documented ConvNeXt-Tiny ImageNet weights from torchvision; their URL and digest are recorded in the model provenance. Downloaded pretrained weights are not redistributed here.

## 3. Obtain WiMANS and use the exact partitions

Public dataset: https://www.kaggle.com/datasets/shuokanghuang/wimans

No new raw CSI data were generated by this study. Obtain the dataset subject to its upstream terms. Do not assume that this package grants a new license to the original dataset or to third-party materials.

The authoritative final lists are:

```text
reproducibility/manifests/sample_manifest_seed2026.csv
reproducibility/manifests/sample_manifest_seed2027.csv
reproducibility/manifests/sample_manifest_seed2028.csv
reproducibility/manifests/combo_manifest_seed2026.csv
reproducibility/manifests/combo_manifest_seed2027.csv
reproducibility/manifests/combo_manifest_seed2028.csv
```

The activity-vector order is `jump, lie_down, nothing, pick_up, rotation, sit_down, stand_up, walk, wave`. `nothing` is an annotated present inactive person; it is not an empty scene. Use the frozen lists, including the auxiliary zero/one-person partitions, rather than creating new random train/test lists.

CSI input consists of the official amplitude `.npy` files indexed by the public record IDs. Keep the official `wifi_csi/amp` file organization. The loader handles original `[time,3,3,30]` arrays and their explicit valid-time masks; it does not infer padding by treating arbitrary zeros as missing data.

The supplied extractor can check and extract the records referenced by a manifest from the official ZIP:

```bash
python experiments/original_release/scripts/extract_wimans.py --zip /path/to/wimans.zip --output data/wimans --manifest reproducibility/manifests/sample_manifest_seed2026.csv
```

It writes amplitudes beneath `data/wimans/wifi_csi/amp`. Repeat with the other manifests if needed; existing archive-verified files are reused.

### Regenerate the metadata-only partitions

Obtain `annotation.csv` from the official dataset repository:
https://github.com/huangshk/WiMANS/blob/main/dataset/annotation.csv

The verified input SHA-256 is `d95c1efc8b3951e7f1e3a3a3b065d32523132a364e7572f5060dfde6439c6da0`.

```bash
python scripts/build_wimans_splits.py --input /path/to/annotation.csv --output _reproduced/splits
```

The generator specifies all 10,000 candidate draws, same-occupancy count-support checks, the recording-balance and marginal-distribution score, and deterministic tie-breaking. Its diagnostic output does not use CSI or model outcomes. Compare the generated CSV rows with the authoritative manifests before training; use `scripts/check_package.py --rebuilt-splits _reproduced/splits`.

## 4. Retrain a selected configuration

The root `configs/index.json` enumerates 81 reported model roles: original main/ablation jobs plus the nine direct-head occupancy controls. A role can reuse an original parent checkpoint; 81 roles are not a claim of 81 unique newly trained models. `reproducibility/selection.json` preserves the original validation-selection evidence. No test result is used by the runner to choose a configuration.

```bash
python scripts/run_selected.py --list
python scripts/run_selected.py --job main/ours_v4_s2026_m2026 --data-root /path/to/wifi_csi/amp --output-root runs/reproduction
```

The second command is a dry run. It creates `relocated_config.json`, changing only the data manifest, data root, cache root, and run-output paths. To train, explicitly append `--execute`:

```bash
python scripts/run_selected.py --job main/ours_v4_s2026_m2026 --data-root /path/to/wifi_csi/amp --output-root runs/reproduction --execute
```

For the matched simple-head model, use `--job direct_occ_s2026_m2026`. The runner activates the supplied direct-head extension and retains its original scientific source hash. Do not use the generic development defaults to reproduce the reported configurations.

After training, evaluate the newly selected checkpoint:

```bash
python scripts/evaluate_checkpoint.py --checkpoint runs/reproduction/main__ours_v4_s2026_m2026/best.pt --data-root /path/to/wifi_csi/amp --output runs/reproduction/evaluation --device cuda
```

The same evaluation helper also activates the direct-head model when required. The `best.pt` selection follows the original validation rule. Keep test evaluation separate from training/model selection.

## 6. Anonymization, provenance, and limitations

- No manuscript author names, affiliations, contact details, credentials, Git history, raw CSI, or trained weights are intentionally distributed.
- Personal absolute paths in archival metadata are replaced with `${PROJECT}`, `${CSI_ROOT}`, `${CACHE}`, `${HOME}`, or `${WORKSPACE}` placeholders. Use the relocation runner for training; do not execute an archival placeholder path directly.
- The frozen scientific implementation and numerical predictions are preserved. Digests for metadata files modified by anonymization describe the distributed bytes; the transformation is listed in `protocol/anonymization.json`.
- `SHA256SUMS.json` checks the distributed package. It does not substitute for scientific validation or certify an external checkpoint.
- A normal GitHub repository exposes its owner when public. Anonymous contents alone do not make the hosting account anonymous. Keep the owner-associated repository private during review or use a genuinely anonymized review delivery route.
- Scope: fixed activity dictionary, up to three people, existing acquisition conditions, and reference dataset annotations. Statistical intervals, initialization spread, and probability calibration diagnostics are distinct from a complete metrological uncertainty budget.

## 7. Checks

```bash
python scripts/check_package.py
python -m pytest experiments/test_measurement_experiments.py -q -p no:cacheprovider
```

The CPU tests cover decoder equivalence, mask reproducibility/order, and trainable direct-head gradients using a small injected backbone. They do not stand in for rerunning the original GPU study.
